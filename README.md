## 🚀 Projetos em destaque

### 🔐 AccessCore

Sistema web de **gestão e simulação de controle de acesso**, desenvolvido como projeto acadêmico.

O projeto foi inspirado em cenários encontrados em sistemas reais de segurança eletrônica e permite simular o gerenciamento de pessoas, dispositivos e permissões de acesso.

**Principais funcionalidades:**

- 👤 Gerenciamento de usuários
- 🖥️ Cadastro de dispositivos
- 🔑 Configuração de níveis de acesso
- 👨‍💼 Gerenciamento de operadores
- 🛡️ Regras de proteção e acesso
- 🚪 Simulação de entrada e saída
- 📋 Auditoria de eventos
- 📊 Dashboard de acompanhamento
- 📑 Relatórios de acesso

**Tecnologias:**

`Python` `Flask` `SQLAlchemy` `HTML` `CSS`

➡️ [Acessar o projeto AccessCore](https://github.com/RyanMartinsRM/AccessCore)

### 🏠 RyanHUB

Aplicação web pessoal desenvolvida para **centralização e organização de informações**, reunindo diferentes funcionalidades em uma única plataforma.

O projeto também é utilizado como ambiente para aplicar conceitos de desenvolvimento web, autenticação, banco de dados e segurança de informações.

**Principais funcionalidades:**

- 💰 Organização financeira
- 💳 Controle de dívidas
- 📝 Anotações
- 🗂️ Organização por categorias
- 🔐 Autenticação de usuários
- 🔑 Cofre de informações com criptografia
- 🗄️ Persistência de dados
- 👤 Separação de informações por usuário

**Tecnologias:**

`Python` `Flask` `SQLAlchemy` `SQLite` `HTML` `CSS`

➡️ [Acessar o projeto RyanHUB](https://github.com/RyanMartinsRM/RyanHUB)
